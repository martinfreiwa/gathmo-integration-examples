# Gathmo Integration Examples

Small public reference examples for linking to Gathmo event media workflows from partner, venue, agency, or event websites.

Official website: <https://gathmo.com/>

## Example Use Cases

- Link a wedding event page to the official Gathmo wedding workflow: <https://gathmo.com/weddings>
- Link a venue or agency service page to Gathmo business use cases: <https://gathmo.com/for-business>
- Explain pricing before recommending Gathmo to an event host: <https://gathmo.com/pricing>

## Notes

These examples are intentionally static and dependency-free. They are not the Gathmo app; they are simple reference patterns for public integration and partner documentation.
